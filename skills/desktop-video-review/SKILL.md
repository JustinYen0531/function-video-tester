# 本機錄影驗收

## 使用範圍

從使用者平常使用的本機捷徑啟動程式，操作指定功能，交付真實錄影供人工驗收。使用者已有 OBS。影片留在本機，不發布、不上傳 Git，不自動刪除。

## 觸發與分類

- 在採用本技能的專案，每完成事先界定的 ticket、小節或章節，自動執行；也接受「先錄這個功能」的即時要求。
- 這是代理工作流程規則，不是背景監控服務；沒有執行中的 Codex 任務時，不會自行偵測完成事件。
- 開始前由 AI 分類並簡短說明理由：日常維護／成熟功能，交付後可继续下一項；新方向／新流程／展示功能，交付後停下等待使用者確認再推進相關工作。
- 不確定時明說，歸入等待確認類。使用者可隨時改分類。
- 即時要求沿用相同分類規則。只有使用者能將「待審查」改為「人工通過」或「需要修改」。可继续工作不等於已驗收。

## 前置確認

1. 回報目前步驟，讀取專案規則、這次需求及已界定工作範圍。列出要演示的行為與預期結果，僅釐清真正缺少的資訊。
2. 檢查當前是否已允許本次操作與錄影。本技能不能自行覆蓋仍有效的禁止瀏覽器或錄影規則；使用者明確放寬的範圍優先，勿重複詢問已授權的事。
3. 取得目標捷徑與錄影範圍。優先只錄目標視窗；若流程跨視窗，確認所需範圍。避免把無關私密內容錄入。影片本機保存不表示 AI 畫面處理全程離線。
4. 使用已安裝的 Computer Use 技能及其官方執行工具；先讀該技能必要文件。不要自行替換成未授權的 UI 操作方式。
5. OBS 必須開啟且已設定正確來源與保存位置；WebSocket 已啟用。讀取錄影狀態，若已有錄影，不停止、不接管，回報阻擋原因。

## 錄製與交付

讀取 [OBS 操作說明](references/obs.md)，使用配套工具確認連線、開始與停止錄影。工具不設定 OBS 來源，也不驗證捕捉範圍，需先確認畫面。

- 同一桌面一次只執行一項操作錄影，其他要求排隊。
- 在操作前開始錄製，確認 OBS 回報正在錄製，再照驗收項目實際操作。顯示輸入、結果及必要等待；不要製作替代實況的動畫或拼接截图。
- 保留失敗、卡住與重試。每次重試另留紀錄，不挑成功片段冒充整次成功。遇問題先回報、處理或阻擋；不能默認通過繼續。
- 工具失敗、無法操作、影片未保存時，明說未完成；不得以截圖冒充影片。僅停止本次由自己啟動且仍持有的錄影；中斷後先確認狀態及所有權。
- 交付本機影片連結、每個項目的時間點、觀察結果、未測項目和重試。將「操作觀察正常」與「人工通過」分開。
- 確認影片存在且可讀；若能檢查影片內容，確認不是黑畫面或錯誤視窗。未實際播放檢查時明說。影片不證明未呈現的行為、隱藏錯誤或所有品質要求。
- 維護類可继续下一項，仍保留待審查；創新／展示類停在確認點。使用者指出問題後修改並重錄受影響項目。
- 影片由使用者決定刪除；保留簡短驗收紀錄，不自动清理未審影片。程式與技能變更依專案要求提交及上傳 Git；不提交影片、錄影憑證或私密測試資料。

## 驗收紀錄

採用驗收影片中心時，錄製後（包括失敗）讀取中心根目錄 [README 的各專案登記](../../README.md)，使用 `register.js` 將每次結果加入同一個本機中心。若技能已複製到獨立安裝目錄，相對連結不再指向中心，請使用專案規則記載的中心路徑；未記載時只詢問中心位置。影片不複製到 Git，人工通過只能由使用者決定。

每次記錄：工作項目、分類與理由、對應版本、錄影檔、驗收項目及時間點、實際結果、未測範圍、重試、人工審查狀態、是否等待。對使用者以繁體中文及一般用語回報，每完成一步回報結果。
