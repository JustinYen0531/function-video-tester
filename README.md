雙擊桌面的「驗收影片中心」即可開啟。或右鍵 `start.ps1`，選「使用 PowerShell 執行」。需要已安裝 Node.js，不需下載其他套件。

影片、意見、驗收紀錄都留在本機。中心只接受本機連線，不公開網站，不上傳影片。資料保存在此資料夾的 `data/records.json`，影片保留在 OBS 原本位置。備份時請分別保留紀錄和影片。

需要確認的項目優先顯示。維護類交付後可以繼續，但仍待審查；新方向、新流程、展示及不確定項目應等待人工確認。這是執行中代理要遵守的工作流，中心不控制其他專案，也不在背景偵測工作完成。

你可以改分類、留下意見、標記人工通過或需要修改。登記工具永遠建立待審查紀錄，不接受外部提供的人工通過狀態。人工按鈕代表你的決定；此本機工具沒有辨識真人身分的登入機制，代理不得自行操作人工通過按鈕。

刪除按鈕會要求輸入工作項目名稱，永久刪除 OBS 原始影片以釋放空間；紀錄、意見與審查歷史保留。不會自動清理任何影片。共用同一影片的其他紀錄存在時拒絕刪除，避免誤傷。建議 OBS 使用 MP4；其他格式可能需要下載後使用本機播放器。

## 各專案登記

1. 閱讀 desktop-video-review 技能並先分類、說明理由。遵守專案操作授權；同一桌面串行錄製。
2. 使用既有 Computer Use＋OBS 流程，保留失敗和重試；不得挑選成功片段冒充完整成功。
3. 複製 `example-record.json` 到該專案的本機工作目錄，填入真實結果。`video` 填 OBS 回傳的完整路徑；錄製失敗則填 null 並說明原因。`items` 包含時間點、功能與觀察結果。`untested`、`retries` 沒有時填空陣列。
4. 執行以下命令（不需要先開啟中心）：

```powershell
node "C:\你的驗收中心\register.js" "C:\你的專案\本機紀錄.json"
```

`category` 使用 maintenance（日常維護）或 confirmation（等待確認）。登記完成回傳紀錄編號；重新整理中心即可看到。重試各留一筆紀錄。紀錄檔及影片不要放入各專案 Git；程式與說明才提交。

5. 維護類回報影片及未測範圍後可繼續；等待確認類停下，等使用者回覆再推進相關工作。不得自己標人工通過。

## 技能接入

倉庫內 `skills/desktop-video-review` 保存可重複使用的技能與 OBS 腳本。可將這個子目錄複製到你的 Codex 技能目錄（通常為 `$env:USERPROFILE\.codex\skills\desktop-video-review`）；已有安裝時先比較內容，保留個別調整。中心放在哪裡，就在登記命令填入該位置。原本的已安裝版本仍可使用，不需要為了此次 Git 上傳重新安裝。

在各專案 AGENTS.md 加入：

> 採用 desktop-video-review。完成事先界定的 ticket／小節／章節或使用者點名時，依技能分類並錄影；錄製後依驗收影片中心 README 的「各專案登記」寫入共用中心。所有失敗與重試保留。confirmation 交付後等待人工确认，不自行操作人工通過。

這段接入由各專案使用者決定何時採用。本次未操作或修改其他專案，也未更改 OBS 來源或錄製內容。

## 開發與檢查

`node --test test.js` 檢查登記、人工審查入口、影片分段讀取及刪除保留紀錄。`node --check server.js` 檢查語法。未做瀏覽器測試，未驗證實際播放畫面，未實測 OBS 錄影。需要由你在本機確認頁面與影片播放。

此資料夾是獨立 Git 專案，`data/` 和影片已排除。程式與技能保存於 https://github.com/JustinYen0531/function-video-tester 。倉庫公開不代表影片公開；不要手動把錄影、審查意見、密碼或私人紀錄加入 Git。安裝後可執行 `install-shortcut.ps1` 建立桌面捷徑。
